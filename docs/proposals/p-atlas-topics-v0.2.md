# P Atlas v0.2：个人行动能力主题计划

目标：以软件开发和商业为主线，帮助个人获取知识、做出产品、发现需求、交付价值并管理自己的资料与预算。

这是主题研究计划；每个主题内部的可能性仍按现有 P Discovery 的先发现、后归一化和分类流程产生。主题名称不是已确认能力，计划简介不是研究证据。

## 选题依据

- 软件开发把构想变成可交付成果；已有 AI 编程主题之外，补充应用、后端和发布的具体平台。
- 商业研究覆盖真实需求与反馈，再到商品或内容交付；以可验证的经营任务为中心。
- 学习与研究支持持续掌握知识和表达成果。
- 自动化与数据工作支持个人持续运行流程和检查事实。
- 账户、文件与预算管理支持个人经营的日常基础。

## 执行与质量要求

首批由 Luna 同时研究 Next.js、n8n、PostHog；主 agent 先检查原文证据、结果粒度、真实案例和能力边界，再扩大队列。其余主题按目录优先级分为三条并行队列，逐主题完成并复核。批次表示调度优先级，不是固定的研究数量或 P 数量要求。

每项研究保存 possibilities.md、possibilities.json、validation-report.txt、discovery-log.md、source-coverage.json。实际缓存只用于原文核对，不作为网页运行依赖。每一确认结果都要有具体原文支持；记录未支持方向和覆盖缺口，不自授 reviewed。

现有 20 个研究主题、原 Skill 与已上线目录保持不变。新目录在 catalog/p-atlas-topics.v0.2.json；新条目只有通过研究、复核和校验才可改为 ready。当前线上仍使用 v0.1 目录，新版不会因文件存在就自动发布。

支付、银行连接、地区、套餐、版本、扩展维护和实际运行等边界按来源如实描述。客户访谈、预算或产品分析能力不等于已获得市场、投资收益或确定的因果解释。

## 已保留的选题缺口

沟通协作、写作表达、职业机会、健康与日常生活仍有价值；本轮先完成与软件开发和个人经营直接相连的主题。后续应根据用户真正要完成的任务再决定是否扩展，不以主题总量替代价值。
