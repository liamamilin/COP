## 修复内容

1. **参考文件漂移**：种子参考已有 22 个 Stage 的示例、实施细节及 Operation 失败提示，打包参考仍是较旧副本。保留现有种子内容，同步打包副本；更新 enrichment 脚本为一次序列化、同时写出两个文件。原来的逐字节一致性和 schema/count 检查保留。新增回归测试在临时文件里验证同步、内容完整性与重复生成的稳定性。
2. **后端格式**：仅按锁定版本 Ruff 的结果格式化 `capability_map_v0.py` 及对应测试，不改变验证规则或业务逻辑。
3. **数据库认证**：`POSTGRES_PASSWORD` 只配置服务容器，不会自动传给 runner 的 `psql`/`createdb`。为 Backend 和 End-to-end 作业设置临时服务对应的 `PGPASSWORD`；E2E 的 `DB_ADMIN` 指向服务实际创建的 `cop` 角色，避免使用开发机专有的 `milin` 默认值。未改用 trust 认证，未跳过数据库或浏览器测试。
