## 需要用户提供的信息

### 1. 提供者配置（Basic 和 Tools 共用）

```
LC_API_KEY=<your-api-key>
LC_BASE_URL=<your-base-url>
LC_MODEL=<model-name>
```

**示例**（如果使用 OpenAI 兼容接口）：
```
LC_API_KEY=sk-...
LC_BASE_URL=https://api.openai.com/v1
LC_MODEL=gpt-4o-mini
```

### 2. 预算与调用限制

- **最大调用次数**：建议 Basic 3-5 次，Tools 3-5 次（用于验证 + 近邻迁移）
- **费用上限**：用户设定（例如 $1-2）
- **失败处理**：如果真实调用失败，是否记录失败并继续，还是停止？

### 3. 验收标准确认

**Basic 验收**：
- 发送默认问题，检查回复是否合理
- 发送近邻迁移问题，检查是否能迁移
- 人工判断语义正确性

**Tools 验收**：
- 发送产品查询问题，检查工具是否被调用
- 检查工具返回结果与最终回答是否一致
- 发送错误输入（如 P999），检查是否正确处理
- 发送多次调用问题（如"所有教程价格"），检查是否整合多个结果

收到授权后，将按以下顺序执行：
