# Metabase Discovery Log

## 范围与版本

关注个人开发者怎样把数据库结果变成可分享、可交互、可自动更新的报表，或将分析交付给应用客户。官方 docs 页面抓取时显示 v0.65 与 v0.64 LTS；价格页和功能矩阵随时间变化。本次资料日期为 2026-11-05。

## 结果视角：先无分类收集候选

- 用图形界面连接表、筛选、汇总并生成图表。
- 在 SQL 编辑器中查询并保存可复用问题。
- 将问题组合成可筛选仪表板。
- 下载问题结果与仪表板卡片结果为 CSV/XLSX/JSON；仪表板整体 PDF 是可见图表截图，按不同交付形式处理。
- 通过邮件/Slack 定时投送报表。
- 当保存的问题返回结果或时序数据达到目标时告警。
- 定义共享的业务指标公式。
- 在官方电商教程中查看月度收入/订单图表，作为图形化查询成果的具体示例。
- 把仪表板/查询界面嵌入客户产品。
- 集中运营报表并提供多团队/客户的自助分析。

## 教程与案例视角

官方 Learn 教程使用新安装附带的 Examples 集合与电商仪表板，具体展示月度收入和订单图表及继续探索数据的步骤。将此作为图形化查询结果的案例说明合并进该 P，不再单列一个“查看示例”的能力；这是演示数据，不代表用户业务。

Metabase 发布的 Hola Health 客户案例描述 telehealth 运营方把运营报告集中、统一指标并自动发送每日报告。另一个 Synctera 客户案例描述客户/内部用户自助提问和金融服务产品中的客户分析。案例中的企业架构、规模和效果不等于普通安装默认具备，也不是本次独立验证。

## 产品边界与扩展视角

Metabase 自身支持图形化查询器、SQL 查询、dashboard 过滤、指标、导出和告警。每项分析依赖一个已部署的 Metabase 实例和可访问数据库；可选择 JAR、Docker 自托管或 Cloud。

SMTP/Slack/webhook 是通知集成，需要管理员设置邮件/Slack 或权限；这些不会凭空由 Metabase 提供收件服务。产品嵌入是官方能力，不归为第三方 extension：Guest embeds 可在各计划使用，使用签名 JWT 并用锁定参数控制客户数据；访客不登录、不计用户数且不向访客计费。OSS/Starter 会显示 Metabase 品牌。Authenticated embeds/SSO 与 full-app embedding 仅 Pro/Enterprise；商业计划计费需按方案说明的认证/登录用户口径核验，Guest viewers 明确排除在计费用户之外；具体价格仍以实时定价方案为准。

## 归一化与最终分类

将图形查询与 SQL 问题分成不同的创建方式/用户技能；电商教程合并为图形查询的具体演示，不单列学习教程 P。仪表板筛选不与推送订阅合并，主动订阅和告警也产生不同结果。Hola 的运营报告案例与查询器能力区分；Synctera 的客户嵌入案例单列，但未把它重复拆成登录、权限、筛选等流程步骤。导出证据分别读取问题与仪表板卡片段落，整体 PDF 单独解释。Guest viewers 的免计费口径与认证嵌入商业版计费边界分开。最终形成 9 项，按查询、报告、指标、结果分享、自动通知与产品嵌入分组。

## 未采用路径与资料缺口

错误猜测的 public-link、public-sharing、visualizations、data-permissions、CSV upload、question overview 和旧 started guide 路径收到 404，已放入 coverage；没有据此声称产品不支持这些能力。旧 `static-embedding` 路径返回重定向文本，因此以新 guest-embedding 路径取证。对访问公开分享路径的核实不充分，不列入确认成果。

本轮覆盖官方手册、query builder/SQL/filters/subscriptions/alerts/metrics/embed 专页、示例电商教程、Pricing 和真实客户案例。资料新增主要支持候选已收敛的结果；未覆盖每一个数据库驱动、付费 plan 的全部限制、生产安装/安全/性能及多租户隔离的独立验证，故停在 10 个已证实任务。

## 主 agent 来源复核

主 agent 已逐项阅读结果、条件和摘录的周边原文；按实际响应类型区分 Markdown、HTML 提取正文和源文本，并核对 GitHub 固定引用。类型标签累计修正 0 处；引文与原始缓存行号仍逐条匹配。这不授予 reviewed，不是独立人工审核或工具运行认证。
