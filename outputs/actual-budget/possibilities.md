# Actual Budget：个人记账与预算

**范围：** 个人记账与预算：管理账户和交易、分配当前已有资金、按预算类别结转余额、核对对账单、自动化交易归类、计划定期收支、观察账目报表；明确银行连接的地区/供应商/服务器/密钥依赖。只研究软件任务，不提供投资、税务、法律或债务决策结论。

Actual Budget 可辅助记录、核对和回顾收支；它不替你验证支出分类是否正确，也不提供投资、税务、法律结论。银行连接还涉及外部数据提供方与服务器部署。

## 分配资金与规划支出

### 把已有收入分配到月度预算类别

只把已经拥有的钱分配到本月各项开支或储蓄类别，让每笔可用资金有明确用途。 **核心**。

条件与边界：Actual 的 envelope / zero-sum 预算方式以当前实际资金为起点；预算数字仍需个人录入并随实际支出调整。预算结果是记账计划，不保证支出或储蓄目标达成。

来源：[Envelope Budgeting](https://actualbudget.org/docs/getting-started/envelope-budgeting/)。

### 将未用类别余额结转到下个月

让某个月结束时某个类别剩余的钱继续留在该类别下月的可用余额中，便于为不定期开支逐月留存。 **核心**。

条件与边界：这是预算类别中的余额延续，不是独立银行账户或投资产品；不同类别的超支处理方式需按当前预算规则另行设置。

来源：[Budgeting](https://actualbudget.org/docs/budgeting/)。

## 记录账户并核对交易

### 区分纳入预算与仅跟踪余额的账户

把日常现金流账户纳入预算，并将投资、贷款或房产等账户作为只跟踪余额的账目，避免它们直接进入日常类别预算。 **核心**。

条件与边界：Actual 的 on-budget / off-budget 是软件中的账目口径设置，不判断资产应如何配置，也不提供投资、税务或贷款建议。

来源：[Accounts & Transactions](https://actualbudget.org/docs/accounts/)。

### 导入或手工录入交易记录

将银行导出的交易文件导入账户，或为不支持导入的账目手工添加记录，减少把所有消费和收入留在记忆中的负担。 **核心**。

条件与边界：支持 CSV、QIF、OFX、QFX、CAMT；CSV 需匹配列和日期格式。OFX/QFX 的重复交易识别信息较丰富；导入后仍要核对分类、金额和重复项。

来源：[The Account Register](https://actualbudget.org/docs/tour/accounts/)、[Importing Transactions](https://actualbudget.org/docs/transactions/importing/)。

### 把账户流水与银行对账单逐笔核对

将 Actual 账户账簿与银行纸本或线上对账单比较，标记已核实交易并找出金额差异。 **核心**。

条件与边界：需拿到银行对账单或可信的账户余额，逐项核对后再完成 reconciliation；这是账目一致性检查，不构成财务判断。

来源：[Reconciliation](https://actualbudget.org/docs/accounts/reconciliation/)。

## 减少重复记账操作

### 自动清理常见商户名并分类新交易

为常见 payee 规范名称并将符合条件的新导入交易自动放入指定类别，减少反复修改相同交易的工作。 **核心**。

条件与边界：规则基于交易条件执行；Actual 也会从用户重复重命名或分类行为中生成规则。自动结果可能需要检查与编辑，规则不会证明实际消费性质。

来源：[Rules](https://actualbudget.org/docs/budgeting/rules/)。

### 预排重复账单与收入进入账簿

将固定或近似金额的账单、订阅、薪资等设为未来计划交易，可自动记入账户或保留为待手动确认项目。 **核心**。

条件与边界：可设周期与金额近似值，实际金额变化时需更新；定期计划只是预期记录，不会替用户支付账单或保证收入到账。

来源：[Schedules](https://actualbudget.org/docs/schedules/)。

## 观察个人账目表现

### 比较一段时间内的支出并查看账户净值趋势

用报表比较指定期间的开销变化，并查看所有账户余额随时间变化，作为个人账目回顾的可视化资料。 **核心**。

条件与边界：金额与趋势依赖账目完整、分类一致和账户余额更新；净值/支出图表是描述性指标，不是投资、税务、法律建议，也不证明某项支出造成了其他结果。文档标注的实验性分析报表不纳入此项。

来源：[Reports](https://actualbudget.org/docs/reports/)。

## 连接服务与选择部署方式

### 连接受支持银行并同步新交易

借助 Actual 的可选银行连接，把受支持机构的新交易同步到账户账簿。 **扩展**。

条件与边界：需要自行在服务商开户/取得 API 凭据，且须运行 actual-server；密钥保存在服务器数据库中，不受 budget data 的端到端加密保护。支持范围依服务商和地区而异：官方 getting-started 文档列出 SimpleFIN 面向美国/加拿大，并说明 GoCardless 已停止接受新账户；Connecting Your Bank 页面另列地区供应商（如 Pluggy.ai 面向巴西）。这些文档页的供应商列表并不完全一致，应在连接前复核当前状态。同步默认关闭，实际后台同步只在 Actual 仍打开时运行，间隔还受银行刷新限额约束。服务商费用与服务器托管费用需按实际供应商/地区确认，本研究未核价。

来源：[Importing Transactions](https://actualbudget.org/docs/transactions/importing/)、[Connecting Your Bank](https://actualbudget.org/docs/advanced/bank-sync/)、[Starting Fresh](https://actualbudget.org/docs/getting-started/starting-fresh/)。

### 在浏览器本地使用并手工保存预算文件

不搭建服务器时，可在当前浏览器本地使用 Actual 并手工保存预算文件，适合快速开始体验基础记账与预算功能。 **核心**。

条件与边界：官方将这种浏览器路线定位为快速开始，不推荐长期使用；它不提供跨设备同步、自动保存或备份。每次使用后需手工导出/保存预算文件并另存安全副本，浏览器存储清除可能导致数据丢失，不宜把此模式作为长期唯一预算副本。文档关于网页应用不访问个人数据的表述未经独立审计，本研究不据此作更强隐私或安全承诺。对照而言，官方文档列出桌面客户端的离线使用与自动备份，以及 server 提供的跨设备同步和可选银行同步；实际部署与备份策略仍需核实。

来源：[Installing Actual](https://actualbudget.org/docs/install/)。

## 资料覆盖与缺口

- 银行账户覆盖取决于所在地区、银行、provider 与当时是否接受新用户；本轮只按官方文档列出示例，未验证特定个人账户是否可连接。
- 银行同步 API 凭据需由使用者向第三方 provider 申请并存于服务器数据库；文档称其不受预算数据 E2E 加密保护。未审计服务器供应链或托管方安全。
- 银行连接服务、服务器或托管的当前价格、费率和套餐未逐项核价；按实际区域与提供商确认。
- 未测试真实 CSV/OFX 等银行文件导入、去重、自动规则、定期交易和 reconciliation 流程。
- 本地浏览器模式仅推荐快速开始，不推荐长期使用；手工导出/保存流程和恢复未实操。
- 报表只展示依据输入账目的统计结果；不据此作投资、税务、法律或信贷判断。实验性 Balance Forecast / Monte Carlo / retirement projections 不作为推荐结果。

没有安装 Actual，也没有导入或连接真实数据；引文匹配仅确认所摘录文字出现在所记录的实际取回行上，不能验证其语义完整性或实际运行效果。

## 原研究保留的未解决问题

- 浏览器本地模式明确是快速开始路线，不推荐长期使用；实际预算文件的安全保存需由用户手工导出并保存到安全位置。本研究未实操桌面客户端、server 部署或备份恢复，也未审计隐私/安全文案。
