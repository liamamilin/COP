# Topic Registry v0.4 · 领域覆盖与缺口审查

> 记录日期：2026-11-06。**这是有范围的目录种子版，不是已完成的全球生态普查。** 目录中每个子领域都有至少一个候选对象，但绝不表示该子领域已穷尽、对象现行可用或其 P 已研究。

## 总体对账

- **11** 个 Domain，**82** 个 Area，**291** 个 Topic。
- 已发布的研究主题 **20**；已研究但仍在独立 PR 的主题 **18**；尚未执行 P Discovery 的候选 **253**。
- 候选由原 v0.3 清单 **72** 个及基于领域结构补齐的 **181** 个种子组成。新种子是**候选名称，不是事实确认或来源支持的 P**。
- 目录映射覆盖：82/82 子领域有候选；**独立逐子领域资料普查尚未完成，不能报告发现覆盖率**。
- 既有 20 + PR #4 的 18 个研究文件按当前原始状态登记，未移动、替换或发布；尚未合并的 PR 不按已上线计算。
- `area_survey` 属于主题概览性质，可被读者浏览，但默认批次只选择 `bounded_subject` 具体对象，避免 Shiny / R 交互应用的层次混淆。

## 各领域覆盖缺口

### 大模型与 AI 基础

**8 个子领域 · 35 个 Topic（已上线 3 / PR 中 0 / 候选 32）。** 当前以模型工具、训练与推理为中心；模型架构、数据许可、量化评测与新多模态任务需按官方任务索引系统再查。模型出现/可下载不等于许可合适或本机可运行。

### Agent 与智能体系统

**8 个子领域 · 39 个 Topic（已上线 7 / PR 中 0 / 候选 32）。** 框架和开发代理较丰富；协议适配、运行安全、Computer Use、记忆与可观测性仍需对照官方 SDK/版本、用户案例与实施边界。

### 软件工程与应用交付

**8 个子领域 · 30 个 Topic（已上线 0 / PR 中 5 / 候选 25）。** Web/后端/桌面已有代表项，但 iOS/macOS 系统能力、数据库性能、测试矩阵、生产部署与安全是宽子领域；Apple/CNCF 索引仅提供发现入口。

### 数据科学、统计与分析

**8 个子领域 · 26 个 Topic（已上线 2 / PR 中 2 / 候选 22）。** R/Python 与 BI 起点较好；高级统计、空间/时序/因果、领域数据和真实业务案例尚未完成专题普查，可参考 CRAN Task Views。

### AI 内容创作与媒体制作

**8 个子领域 · 35 个 Topic（已上线 3 / PR 中 0 / 候选 32）。** 图像/视频/音乐模型迭代快；本地可运行条件、许可证、声音质量、角色一致性、剪辑、交付成本均需验证，不把模型演示等同于成品工作流。

### 信息获取、搜索与持续监测

**7 个子领域 · 23 个 Topic（已上线 1 / PR 中 0 / 候选 22）。** RSS、爬虫与监控可作为骨架；搜索供应商、信源覆盖、数据使用权、网页改版和实际抓取稳定性需按任务重查。

### 知识管理、学习与研究出版

**7 个子领域 · 23 个 Topic（已上线 2 / PR 中 3 / 候选 18）。** 笔记/引用/学习/出版已分类；研究方法、教育训练、知识图谱、跨工具迁移和用户真实案例仍欠检索。

### 自动化、系统连接与持续执行

**7 个子领域 · 19 个 Topic（已上线 1 / PR 中 1 / 候选 17）。** 已覆盖低代码和浏览器，但系统权限、定时任务、错误恢复、macOS 桌面集成、跨 SaaS 连接需要官方/用户来源核验。

### 产品设计、商业与增长

**8 个子领域 · 29 个 Topic（已上线 0 / PR 中 4 / 候选 25）。** 工具涵盖商业经营各阶段，但行业、地区、支付可用性、商业版资格和实际转化效果不可从工具功能推断。

### 个人数字事务与生活管理

**7 个子领域 · 20 个 Topic（已上线 1 / PR 中 3 / 候选 16）。** 文档/照片/凭据/同步/预算有代表项；隐私、备份恢复、账单、提醒与设备集成需独立测试边界，尤其防止把云服务承诺当作本地能力。

### 认知、表达与行动方法

**6 个子领域 · 12 个 Topic（已上线 0 / PR 中 0 / 候选 12）。** 方法主题不是可安装的软件，必须根据原始研究或可复核的方法定义收集 P；训练效果与主观认知改善不能用工具文档代证。

2. 对所有 `taxonomy_seed_curated` 项核对名称、版本、维护状态、官方原始资料、是否独立研究对象。存疑则标记 `blocked`，不要直接投入大批量 P Discovery。
3. 合并 PR #4 前不得把 v0.2 的 18 个主题称为线上已发布；合并时更新状态和对账，不复制已有研究文件。
4. 对边界相近的主题记录 `related_topics`，例如 MCP / FastMCP、Agent SDK / Agent Harness、LLM Inference / llama.cpp，避免同一研究结果重复归因。
5. 目录仍以用户最近涉及的活动为范围，不包含所有自然科学、社会科学、职业领域或全球软件目录；如要扩大，应先明确新增 Domain，而不是声称现有目录已穷尽。

## 验收含义

**已交付**：领域树、所有旧主题归位、每个子领域至少一个种子对象、状态与批量队列可校验。
