## 领域级仍需补查的缺口

### 大模型与 AI 基础

模型训练数据、量化兼容性、推理测试与许可边界需要分别调查；模型系列、训练库、服务平台不能互相替代。

### Agent 与智能体系统

Agent SDK、运行 Harness、工具服务、记忆与评估应分层；具体框架关系需要官方文档关联。

### 软件工程与应用交付

向量检索、网络连接已设独立子领域；仍需按操作系统与部署环境补充第一手候选来源。

### 数据科学、统计与分析

统计可视化、通用图布局与知识图谱是不同研究对象；时序、空间、因果及真实数据产品仍缺系统调查。

### AI 内容创作与媒体制作

模型、节点工作流、后期和发布服务分层；视频模型兼容、本地运行条件、成本和版权要单独调查。

### 信息获取、搜索与持续监测

SearXNG 已归入元搜索；来源发现与信息汇总、事件通知分离，需补查各信息源的维护情况。

### 知识管理、学习与研究出版

笔记软件与文献管理、知识图谱数据库、学习方法分层；需调查移植、规模和长期数据可用性。

### 自动化、系统连接与持续执行

本地桌面、浏览器与任务调度之间存在交叉；系统权限、账户连接及端到端执行需要独立验证。

### 产品设计、商业与增长

支付、传播、邮件营销、用户增长分属不同阶段；地区可用性和实际商业结果不可仅从供应商功能推导。

### 个人数字事务与生活管理

私人文件、财务与网络服务已分类；原 personal-privacy 移走网络连接项目后为空，公开标记为未播种待发现。

### 认知、表达与行动方法

目前是研究方法与技能的候选示例；需要论文、方法定义及实际训练案例，而不是把方法当作插件工具。

## 已处理的具体归类和身份问题

- Qdrant 从 Agent 连接改归软件工程的「向量数据库与检索基础设施」。
- SearXNG 改归「搜索引擎、研究检索与检索 API」。
- Graphviz 改归「图结构与网络可视化」，而不是知识图谱数据管理工具。
- Tailscale、WireGuard 改归「安全网络连接与远程访问」，不再是个人隐私笼统分类。
- `openai-agent-harness` 与现有 Agent Harness 概览可能重复，独立对象身份不明，已阻断而不是删除。
- 部分相邻主题已登记 `related_topics`，例如 LangChain/LangGraph、MCP/FastMCP、llama.cpp/MLX LM。现阶段并未穷尽全部关联。
- 未播种的「本地优先、隐私与家庭数据服务」明确保留为覆盖缺口，不再以“每个 Area 至少有一个种子”为验收目标。

## 来源与质量含义

已为初步核对的研究对象登记 `official_url`、`identity_evidence_note` 及范围。其他候选的 `official_url` 为空、`identity_status=unverified`，不允许直接变为可执行队列。

注意：这次核对的是**对象身份与入口**，并不是完整验证目标产品在最新版本中能完成哪些任务。要取得 P 仍需运行 P Discovery，独立审核来源与能力边界。

## 仍未交付的目录完整性

1. 对 85 个 Area 分别完成官方生态/实际应用来源普查，并保留查询、被拒候选、来源及补漏记录。
2. 将尚未核验的 253 项旧候选逐项核实身份、维护状态、歧义与来源；其中有一项已阻断，候选数量应以当前研究状态重新计算。
3. 按官方产品关系补齐跨主题关联；不要求所有关系互为唯一父子，也不要求单靠关键词相似判定重复。
4. PR #4 仍未合并，不能擅自更新其 18 项的发布状态。
5. 每次新增、替换、撤回研究对象后重新生成队列，再核对已发布目录。

**结论：目录可用于少量、身份已确认的试验性批次；尚不能宣称已经完成全面 Topic Discovery，也不应该对全部候选开闸批量生成。**
